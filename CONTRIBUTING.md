# Contributing

Open an issue describing the problem or proposed improvement before starting a large change. For bugs, include your browser, operating system, reproduction steps, and expected behavior. Share only images you have permission to publish; do not attach private photos.

Fork the repository, create a branch, install dependencies as described in the README, and make a focused change. Run `pnpm check` and try the affected controls in a browser before opening a pull request. Include what changed and how you verified it.

Keep simulation descriptions accurate: RGB effects must not be presented as measurements of invisible radiation. Preserve local image processing, accessible controls, and existing third-party notices. Identify the source and license of new assets or dependencies.

Contributions to the original application code are submitted under this repository's MIT license unless explicitly agreed otherwise. Be constructive and respectful in issues and reviews.
